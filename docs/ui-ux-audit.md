## 1. 设计令牌一致性盘点

### 1.1 色彩
- `:root` 已定义完整语义色：`--paper/--surface/--ink/--ink-soft/--line/--brand/--cinnabar/--jade/--amber/--side-*`，语义清晰（墨蓝=用户、朱砂=AI、松烟绿=完成、金=进行）。
- **问题（P1）**：全文仍有 **116 处硬编码十六进制色**，且大量与令牌近似/重复：
  - AI 朱砂族近重复：`#C84533`、`#A43A2C`、`#8C3A2C`、`#E5C6C0`、`#E9C2B7`、`#E5B9AF`、`#D8B4AC`、`#F8E3DD`（当前 `--cinnabar`/`--cinnabar-soft`）。
  - 完成绿近重复：`#2F7A55`、`#2C5A42`、`#CFE0D4`、`#E6F6EF`（`--jade`/`--jade-soft`）。
  - 墨蓝近重复：`#4C7391`、`#B7C1CF`、`#D5D9E0`、`#F1F4F8`、`#E9EEF3`（`--brand`/`--brand-soft`）。
  - 金近重复：`#7A5C13`、`#9A6111`、`#EADCB6`（`--amber`）。
  - 中性灰近重复：`#9AA3AB`（应为 `--ink-soft` 或独立 mute）、`#5A6670`、`#415060`、`#A9B0B5`。
  - 纸色深浅变体：`#F8F5EF / #F6F2EA / #F5F1EA / #F3F1EA / #F3F0E8 / #F1EFE8 / #EDEBE4`（`--paper`/`--surface-2` 一带）。
- **影响**：破坏"颜色承载语义"的一致性与可维护性；`--cinnabar` 与 `#C84533` 等并存，AI 动作在不同位置可能呈不同红。
- **建议（P1）**：把语义明确的近重复色收敛到令牌；仅保留真正需要差异化（如 hover/分层的微差）的少量变体，并命名化（`--cinnabar-hover` 等）。

### 1.2 字号
- **问题（P1）**：全文 **22 个 font-size 值**（10–26px），含大量 0.5px 近重复：`11 / 11.5 / 12 / 12.5 / 13 / 13.5 / 14 / 14.5 / 15 / 16 / 17 / 18 / 20 / 24 / 25 / 26`。
- **影响**：正文/次要/标签/数据无统一阶梯，阅读节奏与层级感靠"零散数值"撑着。
- **建议（P1/P2）**：定义类型阶梯（如 11=标签 / 12=小注 / 13=次要 / 14=正文 / 16=正文强调 / 18=小节 / 22=页/题 / 26=标题），收敛 0.5px 近重复。

### 1.3 圆角 / 阴影
- `--radius:6px` 已定义，但仍有 `999px`（胶囊）×21、`4px`×11、`3px`×5、`2px`×3、`1px`。
- `--shadow`/`--shadow-lift` 主要已用，但散落 `0 8px 24px rgba(0,0,0,.2)`、`0 0 0 2px rgba(47,79,102,.12)` 等。
- **建议（P2）**：收敛为 `--radius-sm/md/lg` 与 `--shadow-*` 阶梯。

## 4. Nielsen 10 启发式评估

| # | 原则 | 评分(1–5) | 说明 |
|---|---|---|---|
| 1 | 系统状态可见 | 4 | toast/徽章/印章/进度反馈较全 |
| 2 | 与真实世界一致 | 5 | 论文写作心智一致，术语贴近学生/导师 |
| 3 | 用户控制与自由 | 4 | 可撤销（AI/版本/Ctrl+Z）、可回退（向导） |
| 4 | 一致性与标准 | 3 | **语义色/字号有近重复变体，一致性打折** |
| 5 | 防错 | 4 | 删除确认、标题护栏、缺号提示 |
| 6 | 识别胜于回忆 | 4 | 目录/上下文/当前章节可见 |
| 7 | 灵活高效 | 4 | 章节跳转/模板/批量推荐 |
| 8 | 美观与极简 | 3 | 少处留白/密度不平衡 |
| 9 | 帮助用户识别与纠错 | 4 | 错误文案中文可行动 |
| 10 | 帮助文档 | 2 | 无产品内帮助/引导（写作之旅算弱替代） |

> 最低分：**一致性(3)、美观极简(3)、帮助文档(2)**。前两者对应 P1 令牌/字号/密度；第三条可考虑产品内「使用说明/FAQ」（非新功能，列为 P2 建议）。

## 5. 分级问题清单（可执行）

### P0（阻断）—— 无

### P1（明显不一致 / 可感知，建议本轮修）
1. **语义色收敛**：把 AI 家族近重复（`#C84533/#A43A2C/#8C3A2C` 等）与完成绿近重复收敛到 `--cinnabar/--jade` 或命名变体，统一"朱砂=AI、松烟绿=完成"。
2. **字号阶梯收敛**：合并 11/11.5、12/12.5、13/13.5 等 0.5px 近重复，落到统一类型阶梯。
3. **写作台顶部动作密度**：四簇按钮（研究设计/标记完成/复制/工具）与 AI 动作条进一步分清主次，减少争夺注意。

### P2（一致性 / 可维护性 / 观感，可后续）
1. 设计令牌系统化收敛：硬编码色 116 处、圆角/阴影散落 → 建 `--radius-sm/md/lg`、`--shadow-*`。
2. 页面留白/死区统一：主页右下、研究设计、文献页底部。
3. 组件状态与图标统一：检索/批量/导出的 loading 与失败重试文案一致；空态图标统一线性。
4. 动效/焦点反馈规范：成体系的 hover/焦点/过渡（尊重 reduced-motion）。
5. 全局底文字/工具提示：产品内使用说明/FAQ 入口。
6. 真机项：软键盘遮挡、低端机性能（作者自测）。
