## 1. 研究方法与局限

- **方法**：桌面研究——公开调查报告、知乎/小红书/小木虫等社区讨论、应用商店评论（经作者确认采用，未发放一手问卷）
- **数据纪律**：调研素材中已严格区分「有数据支撑的事实」与「基于评论的定性推断」
- **局限**：无一手问卷/访谈，样本偏差可能偏向"有表达意愿"的用户；作者本人即目标用户画像之一（在职 MEM 学生），本报告在画像中标注【作者经验】以补充可信度
- 后续如有机会，可用原型做小范围可用性测试（阶段③原型评审时进行）

## 2. 核心痛点清单（按频率与强度）

| 痛点 | 频率 | 说明 |
|---|---|---|
| **查重 + AIGC 率双重焦虑** | 高频/高强度 | 高校普遍要求双达标（20%–30%，个别 5%）；AI 检测不可靠（《荷塘月色》被判 60%+ AI，唐代诗句被判 100% AI，平台间可差 20+ 个百分点），认真原创的学生也被迫卷入"降 AI"焦虑 |
| **拖延与周期失控** | 高频 | 论文周期数月，缺乏计划与外部监督；在职学生尤其严重（时间碎片化） |
| **选题与开题迷茫** | 高频 | 选题反复更换、不知可行性、大纲不会搭 |
| **文献综述耗时** | 高频 | 文献多而杂，综述无从下手 |
| **参考文献格式繁琐** | 中频 | GB/T 7714 手工排版耗时且易错 |
| **表达与润色** | 中频 | 口语化、冗长、学术表达不规范 |
| **对 AI 的顾虑** | 中频 | 85.5% 担忧学术不端；怕被检测误伤；担心导师态度 |

## 3. 使用行为与态度

**行为分层模型**（对产品边界设计至关重要）：

- **安全区**（普遍）：检索、翻译、润色——学生公开使用，无心理负担
- **灰色区**（普遍但不承认）：续写、降重改写——实际大量使用，但被 AI 检测焦虑笼罩
- **越界区**（少数）：整篇代写、伪造数据——学术不端，产品明确不做

**态度**：使用 AI 本身已无心理门槛，真正的顾虑是"合规确定性"——即如何用 AI 而不被判定为学术不端。这解释了为什么付费集中在检测而非生成。

## 4. 用户画像（Persona）

### 4.1 小李 · 本科应届（22岁）

- **场景**：大四毕业论文，导师催开题，选题已换三次
- **核心痛点**：选题可行性判断、大纲搭建、参考文献格式
- **工具现状**：DeepSeek 免费问 + 手工排版引用，曾买过一次笔杆会员"感觉不值"
- **期望**：输入想法就看到选题方向和大纲雏形；引用格式一键搞定；**免费**
- **产品启示**：选题/大纲模块的输入门槛要低（一个输入框就能起步），格式生成要"复制即用"

### 4.2 王姐 · 在职 MEM 学生（34岁）【作者经验可佐证】

- **场景**：白天上班晚上写作，经常断更两三周，忘记写到哪了
- **核心痛点**：时间碎片化、拖延、进度失控、格式最后才补
- **工具现状**：AI 用于润色和查资料，但没有工具帮她管理"论文这件事"
- **期望**：有倒计时和打卡监督；打开页面就知道"今天该做什么"；零学习成本
- **产品启示**：计划与进度是她的第一需求入口——**该画像验证了写作计划管理作为差异化核心**

### 4.3 陈同学 · 在读研究生（25岁）

- **场景**：小论文 + 学位论文并行，导师要求高，投过稿
- **核心痛点**：文献管理混乱、润色需求高、对 AIGC 检测焦虑（要发表，更怕合规问题）
- **工具现状**：Zotero + 通用 AI，痛点是"引用和写作是断开的"
- **期望**：写作过程中直接产出规范引用；润色可信、可追溯；合规安心
- **产品启示**：文献模块要做"写作中的引用闭环"（借鉴 Jenni.ai 思路）；诚信提示反而是他的加分项

### Should（应该做，时间允许）

- 文献库本地增删改查（完整 CRUD）

### Could（锦上添花）

- 打印/导出 Word 样式

### Won't（明确不做）

| **整篇代写** | 学术不端红线，违背产品合规立场（G0） |
| **AIGC 检测集成** | 政策敏感 + 灰色产业聚集，检测结果不可靠，与产品价值观冲突 |
| 账号系统 / 云端同步 | 无后端约束（GitHub Pages/Netlify 纯静态），本期范围外 |
