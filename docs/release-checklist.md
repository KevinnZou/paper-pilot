# PaperPilot 4.0 Beta 发布候选检查清单

> 版本：4.0.0-beta.1  
> 日期：2026-09-01  
> 目标：冻结新功能，确认核心流程、导出格式和真实 API 交互足够稳定，可交给第一批真实用户试用。

## 发布判断

当前版本建议以 **Beta / 内测版** 发布。功能链路已经覆盖论文项目创建、研究设计、写作工作台、文献与证据、计划记录、模板预览与导出；发布前重点不再扩功能，而是确认真实环境下不会卡住、不会误导、不会丢数据。

## 必测主流程

- [ ] 新用户空数据进入系统，可创建论文项目并进入研究设计。
- [ ] 研究设计可完成：选择题目候选、问卷式收敛方案、生成大纲、采用大纲并进入写作台。
- [ ] 写作台可按章节定位，首页「继续写」可跳到目标章节。
- [ ] 生成当前章节初稿时有加载/流式反馈，用户可继续滚动查看结果。
- [ ] 初稿生成时能检索并引入文献，正文引用与「文献与证据」里的文献库保持同步。
- [ ] 润色、补充论证、重构表达、续写、逻辑检查等 AI 工具不会破坏原文位置，采纳后插回正确位置。
- [ ] 模板预览显示封面、摘要、目录、章节分页、参考文献和页码。
- [ ] Word / PDF / Markdown 导出均可下载，Word 打开后封面、目录、正文层级、章节分页、参考文献格式可接受。
- [ ] 计划与进度页在未设置截止日期时不阻塞主流程，设置后能生成时间轴与今日任务。
- [ ] 数据备份导出/导入可恢复项目、正文、文献、证据卡、版本记录和设置。

## 真实 API 检查

- [ ] 关闭真实调用时，全局 AI 功能都使用演示数据，不消耗用户 Key。
- [ ] 开启真实调用后，题目候选、研究方案、大纲、初稿、润色、文献检索均能返回结果。
- [ ] AI 请求慢响应时按钮有明确进行中状态，页面不假死。
- [ ] AI 请求失败时有用户能看懂的错误提示，不暴露内部调试文本。
- [ ] 大纲、研究问题、收敛选项等结构化返回不出现 `[object Object]`。

## 视觉与交互检查

- [ ] 论文主页、研究设计、论文写作、文献与证据、计划与进度、项目中心、设置页在 1440px 桌面宽度无明显错位、重叠、空白断层。
- [ ] 写作台主导航、左侧论文目录、顶部工具栏、右侧辅助区在目录折叠/展开时都能恢复。
- [ ] 顶部工具栏按钮不截断、不换行成凌乱多排；导出菜单外点和 Esc 可关闭。
- [ ] 文献库与证据卡采用列表/弹窗入口，不再出现左右大卡片交错和大片无意义空白。
- [ ] 390px 移动端核心阅读和写作流程无横向溢出。

## 发布步骤

1. 运行 `npm install` 确认依赖完整。
2. 运行 `npm run build`，确认生产构建通过。
3. 清空浏览器本地数据，用演示模式走一遍主流程。
4. 填入真实 API Key，再走一遍 AI 主流程。
5. 导出 Word/PDF/Markdown 并人工打开检查。
6. 导出备份 JSON，清空数据后导入恢复。
7. 打 tag 或记录发布版本：`v4.0.0-beta.1`。

## 已知非阻塞项

- 构建时 JS chunk 超过 500 kB，当前不影响使用；后续可通过动态 import 或 manualChunks 做拆包。
- 纯前端 BYOK 架构没有账号、云同步和多端同步，适合课程展示与内测；正式商业化需要另立后端与数据同步方案。
