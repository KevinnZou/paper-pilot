1. 产品概述

1.1 背景与动机（调研数据支撑）

论文写作是高校学生的核心学业任务，调研发现六大痛点：

  1. 查重 + AIGC 率双重焦虑（高频/高强度）：高校普遍要求双达标（20%–30%，个别 5%），AI 检测不可靠（同一论文跨平台结果可差 20+ 个百分点），认真原创的学生也被迫焦虑
  2. 拖延与周期失控（高频）：论文周期数月、缺乏计划与外部监督；在职学生时间碎片化，非全硕士按期毕业率仅约 50%
  3. 选题与开题迷茫（高频）：选题反复更换、可行性无从判断、大纲不会搭
  4. 文献综述耗时（高频）：文献多而杂，综述无从下手
  5. 参考文献格式繁琐（中频）：GB/T 7714 手工排版耗时易错；通用 AI 不支持国标，专业工具重、付费、需配置
  6. 表达与润色（中频）：口语化、冗长、学术表达不规范

同时市场已具备产品土壤：高等教育在学 4872.57 万人（教育部 2025 统计公报），大学生 AI 使用率 94%–99%，首选免费国产模型（DeepSeek 72.1%）；但现有工具要么是"无场景的通用 AI"，要么是"单点功能 + 付费墙的论文工具"——缺少一个覆盖全流程、免费、合规导向的轻量助手。

1.2 产品定位（G0 评审通过）

覆盖论文全流程、唯一内置写作计划管理、国标引用合规的轻量助手。

三条产品原则：

  1. 全流程而非单点——选题 → 写作 → 文献 → 进度一条链
  2. 计划管理作为记忆点——利用全行业空白，做"能陪你写完论文"的工具
  3. 合规优先——在 AI 与学术诚信的敏感地带做正确的事，成为信任资产

1.3 产品目标

  1. 降低论文启动与定框架的时间成本（选题+大纲从数天缩短到分钟级）
  2. 写作过程中即时获得学术化润色与摘要辅助
  3. 参考文献格式一键生成，消除手工排版负担
  4. 用计划与打卡机制对抗拖延（全行业空白的能力）
  5. 零成本使用：无需服务器、用户自带 Key，浏览器打开即用
  6. 合规安心：全程学术诚信引导，用户敢用、用得起

1.4 成功指标（课程验收标准）

  • 四大功能模块均可真实使用（AI 功能真实调用大模型 API）
  • 无后端部署：GitHub Pages / Netlify 纯静态托管，演示零失败
  • 用户可在 1 分钟内从打开页面到产出第一条 AI 结果
  • 所有 AI 输出场景均有学术诚信提示（合规立场落地）

4. 产品架构

4.1 信息架构

PaperPilot
├── 仪表盘（进度总览 / 倒计时 / 快捷入口）
├── 选题与大纲（选题建议 / 大纲生成）
├── 写作辅助（摘要 / 润色 / 扩写 / 降重改写）
├── 文献与格式（文献库 / 格式化 / AI解析）
├── 计划与进度（计划模板 / 甘特图 / 打卡）
├── 设置（API配置 / 数据管理）
└── 全局：学术诚信提示（AI输出场景）+ 页脚诚信声明

4.2 核心交互流程

以"生成选题建议"为例：输入方向词 → 点击生成 → 前端校验（Key 已配置？输入非空？）→ 调用大模型 API（加载态）→ 成功：渲染结果卡片（可复制/采用）+ 学术诚信提示条 → 失败：按错误码给出可行动提示（如"Key 无效，请到设置中检查"）。

4.3 页面原型

  • 左侧固定导航 + 主内容区，单页切换无刷新
  • 每个功能 = 「输入卡片 + 操作按钮 + 结果区 + 诚信提示」四段式布局
  • 写作工作台（v2.4）：以「大文本框文档编辑器」为核心——支持「✨ 生成初稿」（基于论文题目+大纲+用户要点生成本章草稿，写入编辑器后用户逐段审阅修改，编辑器已有内容时需确认覆盖）、AI 动作（润色/扩写/降重/续写作用于选中文字，结果替换或插入到文档中，可 Ctrl+Z 撤销）、自动保存/实时字数/首次动笔自动标记"进行中"；摘要生成为"基于已写草稿"的右侧工具（初稿成型后使用）；左栏章节导航（显示各章字数）、右栏文献插入+素材库，全程不离开编辑器
  • 选题建议解析为卡片列表，每条可一键「设为论文题目」；论文主页每章有「去写」直达入口与「继续写作」主按钮
  • 全部操作实时反馈（加载态 / 成功 / 错误 toast）

4.4 模块衔接设计（G3 评审新增 · 论文项目主线）

背景：G3 原型评审反馈——各模块功能可用但彼此割裂，与「全流程」定位存在落差。解决方案：引入贯穿全局的「论文项目」主线，四个模块读写同一份项目数据。

数据模型（localStorage: paperpilot:project）

字段内容写入方
title / degreeType / dueDate论文题目、学位类型、截止日期设置、仪表盘、选题模块
outline采用的大纲章节列表选题与大纲（「采用此大纲」）
chapterProgress各章进度（未开始/进行中/已完成）打卡、写作辅助
stages写作计划阶段计划与进度（与甘特图同步）
materials写作素材（摘要/段落草稿）写作辅助

四条衔接链路

  1. 大纲 → 计划：生成大纲后「采用此大纲」→ 章节成为写作任务目录，与计划甘特图关联
  2. 文献 → 写作：文献库条目可在写作辅助中「插入引用」，直接插入 GB/T 7714 格式（Sprint 2 落地 UI）
  3. 打卡 → 仪表盘：打卡时选择「今天写了哪一章」→ 论文主页显示各章进度条与连续打卡天数
  4. 项目 → 全局：所有模块预填论文题目；顶部展示当前论文；仪表盘重构为「论文主页」聚合视图
  5. 章节 → 写作（v2.2）：写作工作台按大纲章节导航，写作上下文始终关联当前章节；「标记本章完成」同步论文主页
  6. 结果 → 素材库（v2.2）：AI 生成结果可一键「保存为素材」（含章节标签），素材库沉淀摘要与段落草稿，可复制/删除
  1. 选题/章节 → 文献查找（v2.5）：确定选题后或写作时，按语境（论文题目/章节主题）在真实学术数据库（CrossRef）检索推荐文献，用户核对期刊与 DOI 后勾选入库——用真实元数据杜绝 AI 幻觉引用（对应调研发现的"引用真实性"空白）

实施划分：Sprint 1 = 项目状态管理 + 论文主页 + 链路 ①③；Sprint 2 = 链路 ②④ 的 UI 接入；v2.2 打磨 = 写作工作台（链路 ⑤⑥）、选题「设为论文题目」、主页章节直写入口；v2.5 = 链路⑦ 在线文献查找。

5. 技术方案

5.1 总体架构

纯静态前端应用（无后端），托管于 GitHub Pages / Netlify。浏览器直连 DeepSeek（OpenAI 兼容协议），Key 仅存本地 localStorage。

5.2 技术选型与理由（同 v1，调研后无变化）

选择理由
原生 HTML/CSS/JS（ES Modules）无构建链、零依赖、演示稳定；维护性第一
localStorage无需后端数据库，Key / 文献 / 计划数据本地持久化
OpenAI 兼容 API 协议DeepSeek、OpenAI、Moonshot 等任意服务商可切换

5.3 API 集成设计（同 v1）

  • 端点：{baseURL}/chat/completions（默认 https://api.deepseek.com）
  • 模型：默认 deepseek-chat，可在设置中修改
  • 认证：Authorization: Bearer {apiKey}，Key 由用户自行填入，仅存本地
  • 请求：非流式（stream:false）+ 温度按场景（选题 0.8 / 润色 0.3）
  • 错误映射：401→Key无效、402→余额不足、429→限流、网络错误→连接失败

5.4 提示词工程（v2 新增合规约束）

  • 系统提示词：学术导师角色 + 合规约束（"不代替用户完成整篇论文（整篇代写）；基于用户提供的大纲、要点撰写章节草稿属于允许的辅助，但须提醒用户亲自审阅、补充个人观点与数据；改写需保留原意并提醒用户自行核实"）
  • 降重改写提示词加入合规使用说明，输出附诚信提示
  • 输出要求：直接给正文结果、避免客套话

5.5 学术诚信提示实现

  • 前端静态文案，不依赖 AI：结果区提示条（写作辅助/选题大纲的 AI 输出下方）+ 页脚全局声明
  • 文案：「AI 生成内容仅供参考，观点与数据请自行核实，并遵守所在学校的学术规范」

5.6 数据设计（localStorage 键值表，同 v1）

Key内容
paperpilot:configapiKey / baseURL / model
paperpilot:citations文献条目数组
paperpilot:plan计划阶段、关键日期
paperpilot:checkins打卡记录

5.7 安全与隐私（同 v1）

  • API Key 仅存浏览器本地，不写入代码库、不上传任何服务器
  • 页面内提供「数据说明」，告知用户所有数据保存在本地
  • 代码仓库中不出现真实 Key（.gitignore + 敏感信息检查）

6. 非功能需求

  • 兼容：Chrome / Edge / Safari 近两年版本
  • 响应式：桌面优先，窄屏下导航折叠
  • 性能：首屏静态资源 < 500KB，无外部依赖
  • 可用性：所有错误有可行动的中文提示；无网络时可演示规则类功能（文献格式、计划、打卡）

1. 市场概况

1.1 目标市场

  • 中国高等教育在学人数 4872.57 万人（教育部《2025 年全国教育事业发展统计公报》），年毕业生 1100 万+
  • 其中每年有论文写作需求的（毕业班 + 研究生 + 课程论文）保守估计约 50% ≈ 2400 万人/年
  • 在职研究生（非全日制 MBA/MEM 等）持续增长，其按期毕业率仅约 50%，时间稀缺问题突出

1.2 AI 渗透与使用偏好

  • 大学生 AI 使用率 94%–99%（中青校媒调查 99.2%，n=3129；多份调查相互印证）
  • 工具首选国产免费模型：DeepSeek 72.1%、豆包 69.85%，ChatGPT 仅 7.5%
  • 85.5% 学生担忧学术不端风险；使用行为分层：检索/翻译/润色（普遍）→ 续写/降重（普遍但不承认）→ 整篇代写（少数越界）

1.3 付费行为：钱花在哪

  • AI 生成本身付费意愿低：笔杆 108 元/年会员被评"结果不理想"，秘塔 24–48 元/月被评"逼氪"
  • 付费集中在"检测合规"：知网 AIGC 检测 2 元/千字符（5.8 万字单次约 120 元），双平台自检单次 35–500 元，学生反复检测累计可达上千元——被动刚需，且伴随"被割"的负面情绪
  • 结论：学生愿意为"合规确定性"买单，不愿意为"AI 生成"买单

2.3 关键结论

  1. 「写作计划管理」是全行业空白：15 个国内竞品中仅笔杆网有基础进度提醒；国外学术工具均无。论文是长周期多里程碑任务，这是明确差异化机会。
  2. 国标引用存在"够得着但不顺手"的断层：通用 AI 不支持、专业工具重、Zotero 要手动装样式——轻量解决方案是补位机会。
  3. 「写—检—改」闭环缺失：写作工具与检测平台割裂，且不同平台 AIGC 检测结果差异巨大（案例：PaperPass 59% vs 维普 25%），"可追溯引用 + 合规引导"是可持续的差异化路线。
  4. 国外趋势值得借鉴：Paperpal/Grammarly EDU/Writefull 把"学术诚信合规"做进产品形成护城河；免费策略多用按量配额而非功能阉割——BYOK 模式天然是"按量"。

4. 差异化定位（G0 评审结论 ✅）

产品定位：覆盖论文全流程、唯一内置写作计划管理、国标引用合规的轻量助手。

三条产品原则：

  1. 全流程而非单点——选题 → 写作 → 文献 → 进度一条链，而不是又一个润色工具
  2. 计划管理作为记忆点——利用行业空白，做"能陪你写完论文"的工具，而非"写完即走"的工具
  3. 合规优先——在 AI 与学术诚信的敏感地带做"正确的事"，成为产品信任资产

合规立场（G0 通过）：

  • 所有 AI 功能内置学术诚信提示（如"AI 生成内容仅供参考，观点与数据需自行核实"）
  • 明确不做整篇代写——产品边界写入 PRD
  • 降重改写定位为"帮助理解与表达"，输出附带合规使用指引
  • 不集成 AIGC 检测——检测是政策敏感区 + 灰色产业聚集地（降 AI 服务伴随论文泄露、被勒索风险），与产品价值观冲突

3. 使用行为与态度

行为分层模型（对产品边界设计至关重要）：

  • 安全区（普遍）：检索、翻译、润色——学生公开使用，无心理负担
  • 灰色区（普遍但不承认）：续写、降重改写——实际大量使用，但被 AI 检测焦虑笼罩
  • 越界区（少数）：整篇代写、伪造数据——学术不端，产品明确不做

态度：使用 AI 本身已无心理门槛，真正的顾虑是"合规确定性"——即如何用 AI 而不被判定为学术不端。这解释了为什么付费集中在检测而非生成。

4.1 小李 · 本科应届（22岁）

  • 场景：白天上班晚上写作，经常断更两三周，忘记写到哪了

  • 工具现状：AI 用于润色和查资料，但没有工具帮她管理"论文这件事"
  • 期望：有倒计时和打卡监督；打开页面就知道"今天该做什么"；零学习成本

  • 工具现状：Zotero + 通用 AI，痛点是"引用和写作是断开的"
  • 期望：写作过程中直接产出规范引用；润色可信、可追溯；合规安心
  • 产品启示：文献模块要做"写作中的引用闭环"（借鉴 Jenni.ai 思路）；诚信提示反而是他的加分项

四、关键发现：市场空白点与机会（5 条）

  1. 「写作计划管理」是全行业空白：15 个调研对象中，仅笔杆网有最基础的「写作进度提醒」，通用 AI 完全依赖用户自行规划。论文写作是典型的长周期（数周至数月）、多里程碑（选题→综述→初稿→降重→格式→查重）任务，一个内置「任务拆解 + 里程碑 + 提醒 + 进度可视化」的写作计划管理模块是明确差异化机会，且能与 AI 生成能力形成粘性。
  1. GB/T 7714 引用格式存在「够得着但不顺手」的断层：通用 AI（DeepSeek/Kimi/豆包/文心/ChatGPT）均不原生支持国标格式；知网研学/NoteExpress 支持但绑定其生态或需付费；Zotero 需手动安装中文社区样式与插件；而主流的论文 AI 工具（秘塔/火龙果/千笔/迅捷/文赋）只宣称「自动生成参考文献」，格式规范、中英混排细节与引用真实性（防幻觉引用）均无保障。一个「输入即出 GB/T 7714 规范化引用 + 引用可溯源验证」的功能是刚需切口。
  1. 写作工具与检测工具割裂，「写—检—改」闭环缺失：查重/降重/AIGC 检测基本由 PaperPass、知网、维普等独立检测平台承担，论文 AI 工具大多不带检测能力（或自带检测权威性不足）；且不同平台 AIGC 检测结果差异巨大（案例：PaperPass 59% vs 维普 25%），学生需要多方交叉验证。内置「自查 + 多源对比报告 + 定向降重/降痕」的闭环，以及「检测结果透明化」本身，都是机会。
  1. 价格敏感度极高，学生端付费意愿分层明显：行业价格带从千笔 AI 的按篇 49.9 元、迅捷的百元级终身，到火龙果近 2000 元/年、豆包学生 38 元/月的订阅不等；多数免费额度（秘塔 8000 字/天、火龙果 250 字/天）对一篇万字论文明显不够。面向本科生的「低价按需（按篇/按字数）+ 高校采购通道」组合，以及家庭/机构端的订阅分层，比单一订阅制更有市场。
  1. 学术伦理收紧催生「合规 AI 辅助」定位窗口：2025–2026 年高校普遍引入 AIGC 检测（多校红线 20%–30%，部分校 15%）并发文规范 AI 使用（禁止 AI 代写核心环节），「毕业生与 AIGC 斗智斗勇」成社会议题，降 AIGC 率已形成 3 元/千字到数百元/篇的付费市场。与「绕过检测」的灰产定位相反，「可追溯引用、AIGC 率可控可解释、与高校规范条款对齐」的合规型辅助工具（如写作过程留痕、引用溯源报告）是更可持续且可进入高校采购体系的差异化路线。

四、关键发现：值得借鉴的产品设计（5 条）

  1. 「按量额度」式免费策略，而非「功能阉割」式：Paperpal（每日 5 次 AI 功能、每月查重字数）、Consensus（每月 15 条 Pro 消息、3 次 Deep Review）、Jenni（每日生成字数）都用「次数/字数配额」让免费用户完整体验核心功能但逼真付费。相比一刀切锁定功能，这种策略既保体验又促转化，值得参考。
  1. 「文献库 → 文中引用 → 自动参考文献」的写作闭环：Jenni 把 PDF 文献库解析后直接提供上下文引用并自动生成参考文献；Zotero 新增 Word 内「Cite from PDF」。把引用能力内嵌在写作发生的地方（而非事后补引用），是学术写作工具的核心差异化——纯润色工具（Writefull、Grammarly）在这一环明显偏弱。
  1. 「引用证据力」可视化，超越「引用格式」：Scite 把每条引用标注为支持/反对/提及并提供原文引句，Consensus Meter 展示研究间共识度。学术工具若能把「引用对了」升级为「引用可信」，将显著提升信任感与付费意愿。
  1. 面向投稿/学术诚信的合规功能包：Paperpal 的 Manuscript Check（30+ 项投稿前检查、对齐期刊指南）与 AI 内容检测、Grammarly EDU 的 Authorship 追踪、Writefull 的审计式修订记录——把「工具能力」与「学术诚信合规」绑定，直接切中高校与期刊的刚需，也是通用写作工具无法复制的护城河。
  1. 开源生态与「组织+写作」一体化路线：Zotero 原生 AI 助手 + 免费开源插件群（AIdea、Zotero-AI-Butler 等）证明「免费基础设施 + 社区生态」可抢走大量基础需求；Notion 则以「写作 + 资料 + 计划管理」一体化覆盖学术项目全周期。垂直写作工具的生存空间在于把论文写作的深度功能做透，而不是与通用平台拼广度。

中国高校学生论文写作痛点与 AI 写作工具使用行为 — 桌面研究

研究时间：2026-08-13<br>研究方法：桌面研究（WebSearch / WebFetch 检索知乎、豆瓣、小红书、小木虫、黑猫投诉、媒体报道、学术期刊与调查数据）<br>研究对象：本科生 + 研究生（含在职/非全日制研究生）<br>数据纪律：本文严格区分「有数据支撑的事实」与「基于评论的定性推断」。推断处明确标注【推断】。

0. 执行摘要

  1. 论文写作的痛点已从「查重降重」扩展为「查重 + AIGC（AI 率）双重焦虑」：高校普遍要求重复率与 AI 率双达标，检测结果平台间差异大、误判频繁，催生了「学生用 AI 写、学校用 AI 查、商家用 AI 降」的产业链闭环。
  2. 学生 AI 使用率极高（多个调查显示 94%~99%），但普遍存在「用 AI 但怕 AI 被查」的矛盾心态；写作行为分层明显：检索/润色/查资料（安全地带）→ 写初稿/代笔（风险地带）。
  3. 付费集中在「查重 / AI 检测 / 降重 / 降 AI」等刚需性检测场景（属被动付费、无奈消费），对「AI 生成内容」本身付费意愿低；降 AI 灰色服务（2–5 元/千字）风险高（论文泄露、被勒索）。

    • 写作/润色类：秘塔写作猫、火龙果写作、千笔、达奇 AI、CNKI AI（知网官方，校园网开通）、豆包/Kimi 内嵌写作
    • 降 AI 类（灰色）：各类「降AI率」「去AI味」网站与人工服务（2–5 元/千字）
    • 【来源】毕业生与AIGC斗智斗勇（中青报）；秘塔写作猫测评合集（36氪AI测评）；千笔百度百科；CNKI AI 开通通知
  • 校园合规工具：南京大学「南雍闻道」等高校自建 AI 学术平台（需统一身份认证）【来源：南雍闻道】

2.3 使用行为分层（基于评论的定性归纳，【推断】）

  • 第一层「安全使用」（多数人）：文献检索、资料总结、翻译、润色、查错、生成大纲、问思路。评论区公认「合理辅助」。
  • 第二层「灰色使用」（常见）：用 AI 续写/扩写初稿、改写降重、按 AI 结果组织文献综述——普遍但不愿公开承认。
  • 第三层「越界使用」（少数）：整篇 AI 代写（一字未写、AI 率 95%+）、AI 伪造数据/图片、购买降 AI 套餐、拼单购买 AI 服务。
  • 【来源】人民锐评：给AI代写论文提个醒；AI代写批量生产论文，如何让学术回归真实；麦可思报告报道

2.4 主要顾虑

  1. 学术诚信与合规（占比最高的公开表态）：85.5% 的大学生担忧 AI 使用不当引发学术不端；高校密集出台政策，明确「允许辅助、禁止代写」【来源：麦可思报道；清华大学指导原则；东北财经大学AI工具使用规定】。
  2. 被 AI 检测「抓包」：AI 率成为硬性门槛（学校上限 20%–40%，导师可要求 5% 以下）；担心误判无法自证。这是 2025–2026 年新增的最强焦虑【来源：大河报/今日头条；中青报】。
  3. 导师态度：导师从「不知道你在用」到「要求证明非 AI 写」，态度分化；被老师发现后多要求整改/自证【来源：大河报】。
  4. 费用：查重 + AIGC 双重自检费用翻番（单次 35–500 元）；平台结果不一致导致反复付费；免费额度不够用（秘塔每天 8000 字纠错/2000 字翻译）【来源：澎湃：双重查重；36氪AI测评：秘塔】。
  5. AI 质量与能力边界：生成内容「模板化、无深度」；改写出错（专业术语被替换）；AI 论文「有理无思」、导师能识别【来源：36氪AI测评；AI进校园，疏堵之间守护育人初心】。

2.5 高校政策环境（影响行为的强约束）

  • 清华（2025-11《人工智能教育应用指导原则》）：严禁 AI 代写、剽窃、伪造，严禁将 AI 生成文本直接复制提交，要求披露声明。
  • 复旦（2025-01）：首个本科毕业论文 AI 使用规定，禁止 AI 用于研究设计、数据分析、论文撰写等六类场景。
  • 天津科技大学：本科毕业论文 AIGC 占比原则上 ≤40%。华东师大/北师大（2024-07）：AI 生成内容不得超过全文 20% 且需标注。
  • 广东石油化工学院：严禁用 ChatGPT/DeepSeek/Kimi/豆包直接生成论文内容，违规论文直接「不通过」并纪律处分。
  • 南京大学：明确 AIGC 检测仅作辅助参考，不作为原创性判定依据。
  • 【来源】清华大学；多所高校出手（澎湃）；人民网：一高校规范AI应用；东北财经大学

3.2 免费 vs 付费接受度（定性推断）

  • 【推断，基于评论】免费优先是绝对主流：学生首选免费/低频自检（checkbug 每日免费、学信网万方/大雅各免费一次），DeepSeek 等免费大模型使用率远高于付费的 ChatGPT，即是明证。社区中「白嫖攻略」「免费查重合集」类内容热度极高。
  • 【推断，基于评论】对「AI 生成内容」付费意愿低、对「检测合规」付费意愿高（但被动且不满）：评论普遍认为 AI 生成结果「不值会员费」（笔杆用户花 108 元后评价「结果相当不理想」）；而查重/AIGC 检测因与毕业强挂钩，成为不得不付的钱，付费时普遍伴随「被割」「知网垄断」「吃相难看」的负面情绪。
  • 【推断，基于评论】能接受的合理付费区间：单次 <20 元（查重/AI 检测单次）较普遍接受；包月会员 20–50 元存在一定接受度（参照秘塔 24/48 元、笔杆 28 元定价在同类中价位），但前提是「明显省时间且不增加风险」。
  • 【推断，基于评论】「降 AI 率」是当前付费意愿最强的新场景：尽管属灰色服务，因 AI 率直接卡毕业，仍有大量学生（含认真原创者）被迫购买——这是刚需驱动的付费，但信任度极低（评价普遍负面）。

3.3 付费投诉高频问题（影响购买决策）

  • 结果不准还难退款：PaperPass「收费和免费报告一模一样」、虚报 68% AIGC 率诱导买套餐；笔杆充值 398 元后系统显示积分为零、客服 4 天不回复【来源：黑猫投诉、山东商报、笔杆黑猫投诉】。

4. 用户画像素材（基于上述资料提炼）

画像 A：「赶稿焦虑型」本科毕业班学生（约 50% 本科群体【推断】）

  • 特征：大四/专科毕业班；写作基础一般；第一次写大篇幅论文；情绪敏感、完美主义与拖延并存。
  • 目标：论文过查重（<30%）、过 AI 率（学校线 20–40%）、顺利答辩拿学位；越快越好。
  • 痛点：选题被驳回、不知道写什么；初稿迟交率高（52.5%）；降重降 AI 双重折磨；检测费贵、平台结果打架；极限赶稿（截止前 1–2 个月才开始是常态）。
  • 使用场景：用 DeepSeek/豆包问思路、生成大纲 → 秘塔/火龙果润色 → checkbug/大雅/学信网免费查重 → 付费查重保底 → 通宵降 AI 率；对「一键生成全文」类工具有冲动但普遍因怕被抓而只用辅助功能。
  • 付费特征：预算 0–200 元，集中在检测与降重；对会员制反感。

画像 B：「科研苦行型」全日制硕士/博士生（核心付费人群【推断】）

  • 特征：研二/研三/博士；有科研压力与小论文任务；对学术规范了解较多但时间极紧；部分导师放养。
  • 目标：大论文（5–10 万字）过盲审、导师满意、按时毕业（避开延毕）。
  • 痛点：文献综述组织难、综述被批「堆砌」；盲审/抽检恐惧；导师指导不及时（71.3% 迟交者反馈）；AI 率红线（导师可能要求 <5%）；查重+AI 双重自检费用高（单次 120 元级别）。
  • 使用场景：文献检索/翻译（最安全）、AI 辅助搭框架、自己写核心、机器降重兜底、人工/付费降 AI 率；比本科生更懂「用 AI 但不留痕迹」，也更在意答辩时能否讲清论文。
  • 付费特征：年度总支出可达数百至上千元（检测为主），对可靠垂直工具（能溯源文献、格式合规）付费意愿相对最高。

画像 C：「时间贫困型」在职/非全日制研究生（MBA/MEM/MPA 等，潜力增量人群【推断】）

  • 特征：30 岁上下职场人；工作日上班、周末上课；写作荒疏多年；导师见不到面；「能过就行」心态明显。
  • 目标：在不辞职的前提下完成 2–3 万字论文，顺利答辩；减少返工。
  • 痛点：时间碎片化、拖延（非全硕士按期毕业率仅约 50%）；工学矛盾突出；论文质量要求与全日制一致；与导师沟通少、惧怕导师、卡点交稿。
  • 使用场景：深夜/周末用 AI 整理思路、把工作内容转成论文素材、AI 润色「去口语化」；需要「帮我把材料变论文」式的强辅助；对代写和「包过」服务警惕性与诱惑并存。
  • 付费特征：支付能力最强，但时间最宝贵——愿意为「省时间、免返工」付费（如辅导班/结构化模板/格式自动处理），对「按字计费的 AI 生成」兴趣低。

1.1 目标市场

  • 中国高等教育在学人数 4872.57 万人（教育部《2025 年全国教育事业发展统计公报》），年毕业生 1100 万+
  • 其中每年有论文写作需求的（毕业班 + 研究生 + 课程论文）保守估计约 50% ≈ 2400 万人/年
  • 在职研究生（非全日制 MBA/MEM 等）持续增长，其按期毕业率仅约 50%，时间稀缺问题突出

1.2 AI 渗透与使用偏好

  • 大学生 AI 使用率 94%–99%（中青校媒调查 99.2%，n=3129；多份调查相互印证）
  • 工具首选国产免费模型：DeepSeek 72.1%、豆包 69.85%，ChatGPT 仅 7.5%
  • 85.5% 学生担忧学术不端风险；使用行为分层：检索/翻译/润色（普遍）→ 续写/降重（普遍但不承认）→ 整篇代写（少数越界）

1.3 付费行为：钱花在哪

  • AI 生成本身付费意愿低：笔杆 108 元/年会员被评"结果不理想"，秘塔 24–48 元/月被评"逼氪"
  • 付费集中在"检测合规"：知网 AIGC 检测 2 元/千字符（5.8 万字单次约 120 元），双平台自检单次 35–500 元，学生反复检测累计可达上千元——被动刚需，且伴随"被割"的负面情绪
  • 结论：学生愿意为"合规确定性"买单，不愿意为"AI 生成"买单

2.3 关键结论

  1. 「写作计划管理」是全行业空白：15 个国内竞品中仅笔杆网有基础进度提醒；国外学术工具均无。论文是长周期多里程碑任务，这是明确差异化机会。
  2. 国标引用存在"够得着但不顺手"的断层：通用 AI 不支持、专业工具重、Zotero 要手动装样式——轻量解决方案是补位机会。
  3. 「写—检—改」闭环缺失：写作工具与检测平台割裂，且不同平台 AIGC 检测结果差异巨大（案例：PaperPass 59% vs 维普 25%），"可追溯引用 + 合规引导"是可持续的差异化路线。
  4. 国外趋势值得借鉴：Paperpal/Grammarly EDU/Writefull 把"学术诚信合规"做进产品形成护城河；免费策略多用按量配额而非功能阉割——BYOK 模式天然是"按量"。

4. 差异化定位（G0 评审结论 ✅）

产品定位：覆盖论文全流程、唯一内置写作计划管理、国标引用合规的轻量助手。

三条产品原则：

  1. 全流程而非单点——选题 → 写作 → 文献 → 进度一条链，而不是又一个润色工具
  2. 计划管理作为记忆点——利用行业空白，做"能陪你写完论文"的工具，而非"写完即走"的工具
  3. 合规优先——在 AI 与学术诚信的敏感地带做"正确的事"，成为产品信任资产

合规立场（G0 通过）：

  • 所有 AI 功能内置学术诚信提示（如"AI 生成内容仅供参考，观点与数据需自行核实"）
  • 明确不做整篇代写——产品边界写入 PRD
  • 降重改写定位为"帮助理解与表达"，输出附带合规使用指引
  • 不集成 AIGC 检测——检测是政策敏感区 + 灰色产业聚集地（降 AI 服务伴随论文泄露、被勒索风险），与产品价值观冲突

3. 使用行为与态度

行为分层模型（对产品边界设计至关重要）：

  • 安全区（普遍）：检索、翻译、润色——学生公开使用，无心理负担
  • 灰色区（普遍但不承认）：续写、降重改写——实际大量使用，但被 AI 检测焦虑笼罩
  • 越界区（少数）：整篇代写、伪造数据——学术不端，产品明确不做

态度：使用 AI 本身已无心理门槛，真正的顾虑是"合规确定性"——即如何用 AI 而不被判定为学术不端。这解释了为什么付费集中在检测而非生成。

4. 用户画像（Persona）

4.1 小李 · 本科应届（22岁）

  • 场景：大四毕业论文，导师催开题，选题已换三次
  • 核心痛点：选题可行性判断、大纲搭建、参考文献格式

  • 产品启示：选题/大纲模块的输入门槛要低（一个输入框就能起步），格式生成要"复制即用"

4.2 王姐 · 在职 MEM 学生（34岁）【作者经验可佐证】

  • 场景：白天上班晚上写作，经常断更两三周，忘记写到哪了
  • 核心痛点：时间碎片化、拖延、进度失控、格式最后才补
  • 工具现状：AI 用于润色和查资料，但没有工具帮她管理"论文这件事"
  • 期望：有倒计时和打卡监督；打开页面就知道"今天该做什么"；零学习成本
  • 产品启示：计划与进度是她的第一需求入口——该画像验证了写作计划管理作为差异化核心

4.3 陈同学 · 在读研究生（25岁）

  • 场景：小论文 + 学位论文并行，导师要求高，投过稿
  • 核心痛点：文献管理混乱、润色需求高、对 AIGC 检测焦虑（要发表，更怕合规问题）
  • 工具现状：Zotero + 通用 AI，痛点是"引用和写作是断开的"
  • 期望：写作过程中直接产出规范引用；润色可信、可追溯；合规安心
  • 产品启示：文献模块要做"写作中的引用闭环"（借鉴 Jenni.ai 思路）；诚信提示反而是他的加分项
