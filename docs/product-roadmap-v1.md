## 1. 商业化路径结论（B vs C）

**近期主推 C（学校 / 教师 / 班级 B2B2C），B（托管额度 + 云同步订阅）作为后端放开后的第二阶段。**

- **选 C 的理由**：C 的交付物大多是**纯前端内容 + 导出物**，在「无后端、数据本地」约束下即可落地并形成付费点：
  - 分学位 / 分学校的**模板包**（封面、页眉、参考文献、致谢差异）
  - **合规说明包**（面向导师 / 学校的 AI 使用透明说明，可导出 / 分享）
  - **导师 / 进度报告**（按项目生成，可导出给导师或存档）
  - 面向院系 / 班级的**批量授权使用说明**（B2B2C 的采购入口）
- **选 B 的前提**：托管额度计量、账号体系、云同步——都依赖后端，与当前「无后端」红线冲突；**待作者决定放开红线后单独立项**。
- **过渡动作**：现在可先把 C 的「模板包、合规说明包、导师报告」这些纯前端可交付的内容做出来，作为未来 B2B2C 的销售物料与差异化证据。

## 2. 目标人群策略

- **总体兼容**：本科生 / 硕士 / 博士 / 在职，一条主线（选题→写作→文献→进度）不变。
- **针对在职群体的增强**（碎片时间、常断更、需要"我推进到哪"的可视反馈）：
  - **每周复盘**：自动汇总本周字数 / 章节进度 / 打卡，可导出周报。
  - **逾期与断点提醒**：距截止天数、逾期任务、上次写到哪一章的「接着写」提醒。
  - **移动优先**：写作工作台在 390px 下的「当前章节」黏性提示、快速打卡、一键续写。
  - **计划与进度**：今日 / 本周 / 阶段三档视图，强化「今天该干嘛、距截止还差多少」。

> 原则：这些是增量能力，不改变全流程主结构，不压缩学术深度需求。

## 3. 演示 / 试用入口设计（建议）

**目标**：让新用户**0 配置、0 成本、0 焦虑**地体验完整写作闭环，再决定是否配 Key / 用真实 AI。

当前默认 `enableLiveAI:false`（Mock），新用户无 Key 时所有 AI 都走内置假数据——**这其实是现成的"免费演示"能力**，但缺少一个把用户"领进去"的入口与清晰口径。

**建议设计**：
1. **首屏 / 空态**：无项目时首屏给主行动「开始试用 · 无需配置」，点击即用**演示项目 + Mock 模式**走完整闭环（定题 → 大纲 → 写一段 → AI 动作 → 插入引用 → 打卡），全程顶部挂「演示模式」徽章，并在首次访问弹一句"这是演示数据，AI 结果为内置示例；真实结果需到「应用设置」填入你的 API Key"。
2. **口径清晰**：把「演示模式（Mock，不消耗额度、结果可直接丢弃）」与「Live 模式（你的 Key）」做成设置里显式的状态说明，避免用户误以为 Demo 就是真实 AI。
3. **一键演示提升到首屏**：现有「载入演示数据」在设置页，较深；建议在首屏 / 空态 / 论文主页空态增加同样的入口（复用 `loadDemoData`）。
4. **真实引导**：当用户想用真实 AI 时，hero / 设置页引导填 Key + 测试连接；填完自动从「演示」切到「Live」并回首页。
5. **安全**：演示项目用可一键清空的独立项目（或用现有演示项目的"载入覆盖"提示），避免污染真实草稿。

## 4. 分期里程碑（纯前端 · 按无后端约束重排）

### Phase 1 · 信任与留存（纯前端 0–6 周）
- **[P0] AI 前后 diff 预览**：右侧建议框内做"删除线（原文）+ 高亮（新增）"的差分展示，接受 / 放弃一屏完成。
- **状态一致性修复**：① 研究设计回到项目预填（定题回填 `researchDesign.initialIdea/关键词/约束`）；② 写作工作台「正在写」与「当前章节卡」一致（初始化对齐光标）。
- **上手引导 + 分学位 / 分学校模板包**（模板切入写作与导出）。
- **演示 / 试用入口**（§3）+ Word/PDF 导出打磨（带图 / 表 / 题注 / 公式完整）。
- **页面留白节奏统一**（主页右下 / 研究设计 / 文献页底部）+ 计划页任务卡去重双按钮。

### Phase 2 · 差异化与在职增强（纯前端 4–12 周）
- **段落语境推荐引用**：写作时右栏按当前段落语义推荐"这段该引哪些"，一键插 [n]。
- **Zotero / BibTeX / EndNote / 知网批量双向导入导出**。
- **版本历史 diff 可视化**（对比两版草稿）。
- **在职增强**：每周复盘 / 逾期断点提醒 / 移动端「接着写」与当前章节黏性提示。

### Phase 3 · 商业化（需后端，待作者放开红线单独立项）
- 托管 AI 额度档位 + 免费试用额度、账号 + 云同步、学校 / 教师 B2B2C（批量授权 + 导师批注 + 合规包）。
