# PaperPilot v4.0.0-beta.1 Release Notes

发布日期：2026-09-01

## 发布定位

这是 PaperPilot 4.0 的 Beta / 内测候选版。当前版本已经完成从“论文写作辅助工具”到“围绕论文项目持续推进的写作工作台”的主流程重构，适合交给第一批真实用户试用。

## 核心能力

- 论文项目：支持创建项目、项目切换、项目设置、备份导出与导入。
- 研究设计：以问卷式流程完成定题、方案收敛、研究问题/方法/数据/范围选择，并生成可采用的大纲。
- 论文写作：提供结构化编辑器、章节目录定位、章节初稿生成、润色、补充论证、重构表达、续写、逻辑检查、版本保存、图片/表格/公式/注释插入。
- 文献与证据：支持智能检索推荐、CrossRef/OpenAlex 检索、文献库管理、正文引用同步、GB/T 7714 格式化、证据卡管理。
- 排版与导出：支持模板预览、封面、摘要、目录、章节分页、参考文献，以及 Word / PDF / Markdown 导出。
- 计划与进度：截止日期为可选项，支持时间轴、今日任务与打卡记录，不阻塞写作主流程。
- AI 调用：支持真实 API 与演示数据模式切换；演示模式下全局 AI 功能不消耗用户 Key。

## 发布前验证

- `npm run build` 通过。
- 构建产物输出到 `dist/`。
- 当前已知非阻塞提示：Vite 提示单个 JS chunk 超过 500 kB，后续可通过代码拆包优化。

## 已知边界

- 当前仍是纯前端 BYOK 架构，没有账号、云同步和多端同步。
- AI 生成内容仅供辅助，最终观点、数据真实性、引用准确性和学术规范仍需用户自行确认。
- Word/PDF 导出采用通用学位论文模板，不绑定具体学校；正式提交前仍建议按所在学校模板人工核对。
