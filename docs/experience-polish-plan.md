# PaperPilot 现有体验优化计划（冻结新功能）

> - **方向**：不再做大的新功能。只做三件事——**现有功能流程完整性**、**用户交互体验**、**页面 UI**。
> - **依据**：当前代码（V4 Phase 1）+ 全模块走查（Playwright，桌面 1440 / 移动 390）+ 三视角评审 + 历轮反馈。
> - **边界**：合规红线（不做代写/AIGC 检测）、无后端/本地数据约束不动；一切改动不引入新功能模块。
> - **状态**：计划版 v1（2026-08-23，作者拍板方向后制定，供确认范围与优先级）。

---

## 0. 当前走查结论（已完成自动化审计）

- 六模块 + 设置页在 **1440px 桌面**加载：**0 控制台错误、0 横向溢出**。
- 六模块在 **390px 移动端**：**初始有一处横向溢出（论文主页 324px）**，已在本次审计中修复（`.grid-2` 由 `1fr` 改为 `minmax(0,1fr)` + `.grid-2>*{min-width:0}`）——**修复后全模块移动端溢出归零**。
- 顶栏状态徽章已统一三态（真实 AI / 已配 Key 未启用 / 无 Key 演示模式）。
- 结论：**功能层面大体能跑通、无报错、响应式基本健康**；真正的优化点在「流程衔接的细节完整性」「交互反馈的一致性」「视觉节奏与信息密度」三类。

---

## 1. 分类行动清单

### A. 流程完整性保证（每条主流程无断链、无死路、数据一致、可回退）

**A1. 六条主流程走查与补齐（每条做一次 0 → 完整闭环走查，缺口即修）：**
| # | 流程 | 完整性检查点 | 已知风险 |
|---|---|---|---|
| 1 | 新建项目 | 打开创建弹窗 → 必填校验 → 创建并进入 → 徽标/空态即时刷新 | 重复提交、取消、已有时切换正确性 |
| 2 | 研究设计向导 | step1 定题 → step2 方案 → step3 大纲 → 采用 → 衔接写作；任意步可回退 | 采用后数据同步；「已定题/已采用」状态稳定 |
| 3 | 写作工作台 | 选章 → 写 → AI 动作 → 插入引用 → 标记完成 → 版本 → 导出（MD/DOCX/HTML/排版预览） | **章节增删改/移动与 project 同步**；导出带图/表/题注/公式/注释；缺号提示 |
| 4 | 文献与证据 | 检索 → 勾选 → 入库 → 引用 → 状态自查；手动录入/AI 解析/搜索/分页 | 入库后即时刷新；删除被引用文献的警告；搜索词保留 |
| 5 | 计划与进度 | 设截止 → 计划模板 → 甘特/时间轴 → 打卡 | 模板分学位；打卡与章节进度联动；逾期处理 |
| 6 | 检查与导出 | 检查项 → **「去处理」精确跳转** → 导出预览一致 | 去处理定位准确；DOCX 与预览渲染一致 |

**A2. 数据一致性审计（跨模块）**：
- 改题目/截止/学位 → 论文主页徽标、写作首行、计划页、研究设计回显是否即时同步（R18 已验，纳入回归）。
- 写作文档与项目 outline/drafts 双向同步是否在任何编辑路径下都不丢章（R10/R16 已修复，纳入回归）。
- 浏览器刷新 / 关闭重开后的状态恢复（IndexedDB 回填）。
- 数据量上限（约 10 万字）行为与性能基线（R19 阈值纳入回归）。

**A3. 空数据 / 异常数据韧性**：
- 六模块在「清空数据」后空态全部恢复并给出行动（R18 已验）。
- 超长输入、非法日期、无 Key、断网、API 异常等边界的可读中文提示。

### B. 用户交互体验优化

**B1. 反馈闭环（点必有应 / 等必有进度 / 成必有标记）—— 全站复查一次：**
- 所有异步调用：loading / 按钮禁用 / 完成状态（toast / 印章 / ✓）。已大部达标，重点复查文献检索、批量推荐、版本快照、导出类按钮。
- 结果框 filled 态残留清理（生成中 → 完成）。

**B2. 空态即邀请：**
- 检索结果、证据卡、待改清单、版本、素材等空态给行动按钮与去向文案。

**B3. 可发现性：**
- AI 动作需选中文字：选中后浮现**选区快捷工具条**（R21 已做），确认其覆盖所有触发路径（含触屏）。
- 文本编辑器内的「插入引用/素材/模板」在光标处的可发现提示。

**B4. 防误操作：**
- 删除类操作确认（章节/项目/图片已做）；大范围改写可撤销（AI/版本已做）。
- 致命操作（清空数据、载入演示覆盖）二次确认口径一致。

**B5. 键盘 / 触屏：**
- Tab 焦点链、Enter 激活（R23 已验，纳入回归）。
- 触屏撤销/重做按钮（R34）；**软键盘是否遮挡选区工具条**（真机补验，headless 覆盖不到）。

### C. 页面 UI 优化

**C1. 间距与留白节奏统一：**
- 用页面级 gap 替代单卡 margin（R25 主页已做），把同一节奏推广到六模块。
- 消除死区/大空白：研究设计向导、文献与证据底部、检查导出页底。

**C2. 信息密度平衡：**
- 写作工作台右侧「当前章节」卡片 8+ 按钮：按「结构」分组收纳或抽屉化，压降视觉噪音。
- 工作台顶部动作三级分层（主 AI 动作 / 次级工具 / 导出）更清晰（R22、conversation-log 已多次反馈）。

**C3. 层级与语义区分：**
- 论文纸面「标题 / 章节 / 摘要 / 关键词 / 参考文献 / 致谢」视觉层级区分（目前同为 H2 样式，易混）。
- 按钮/卡片/chip/pill 在六模块的形态与语义色（朱砂=AI、松烟绿=完成、墨蓝=用户、金=进行）一致（本次已把「开始试用」由朱砂改回墨蓝，守住语义）。

**C4. 移动端（390px）：**
- 主页写作之旅横向滚动（已加 overflow 防溢出，enabled）；模块导航横条、章节卡黏性提示、toast 边界、触控目标 ≥44px。
- 软键盘遮挡（真机重点）。

**C5. 排版预览 / 导出视觉：**
- 打印级 HTML 与 DOCX/Markdown 渲染一致（图/表/题注/公式/注释/参考文献列表）。

## 2. 验收标准（量化，自动化 + 走查双轨）

- **流程完整性**：A1 六条主流程各一次走查；每项检查点通过（流程可从头走到尾、无死路、数据一致）。
- **交互体验**：KR6 复查全站「反馈闭环」零遗漏；空态全部有行动按钮；键盘/触屏基线（R23/R34）不回归。
- **页面 UI**：六模块桌面 + 390px 零横向溢出、零控制台错误；间距/密度/层级按 C1–C5 统一。
- **总基线**：全量自动化断言不回归（现 558+ 项，若干新增本轮断言）；真机项（软键盘、低端机性能）列入作者自测清单。

## 3. 实施节奏（建议轮次，每轮：修改 → 验证 → 留痕 → 提交）

- **R1（已完成部分）**：移动端论文主页溢出修复 + 网格通用防溢出（`.grid-2` → `minmax(0,1fr)`）。
- **R2**：A1 流程走查 1–4（新建项目、研究设计、写作、文献）缺口补齐 + 回归。
- **R3**：A1 流程走查 5–6（计划、检查导出）+ A2 数据一致性回归。
- **R4**：B 交互体验全站复查（反馈闭环、空态、可发现性、防误操作）+ 修复。
- **R5**：C 页面 UI 统一（间距节奏、信息密度、层级、移动端）+ 回归。
- **R6**：排版预览/导出视觉一致 + 最终全量回归 + 更新 `docs/acceptance.md`。

> 每轮维持现有惯例：改动 → Playwright/走查验证 → `report/dev-log.md` + `report/conversation-log.md` 留痕 → `git commit`。
