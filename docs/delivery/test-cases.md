# PaperPilot 测试用例清单

> 文档版本：v1.0  
> 更新时间：2026-09-03  
> 适用范围：PaperPilot v4.0 在线演示版与本地运行版

## 1. 测试结论

项目具备测试用例与验收记录，当前测试材料分为三类：

1. **构建测试**：通过 `npm run build` 验证项目可打包上线。
2. **流程验收**：围绕“研究设计 → 写作台 → 文献与证据 → 排版导出 → 计划进度”五条核心链路进行人工验收。
3. **历史自动化回归记录**：项目早期验收文档记录过 Playwright 自动化回归，覆盖 35 套件、558 项断言。由于历史自动化脚本未作为最终交付物归档，当前仓库中保留的是验收结果与用例说明，而不是完整自动化脚本包。

因此，如需说明项目测试覆盖情况，可以表述为：**项目已整理正式测试用例清单，并包含构建、功能、交互、AI、导出、数据安全和上线验证等测试范围；后续可继续把人工用例固化为仓库内自动化脚本。**
