# PaperPilot 迭代优化计划

## 1. 范围重新确认

当前版本定位为可上线演示的论文写作辅助系统。Must have 范围包括：

- 多论文项目管理与本地持久化。
- 研究设计问卷、大纲生成与采用。
- 章节化写作台、富文本编辑和 AI 辅助写作。
- 文献检索、引用、证据卡和参考文献格式化。
- Word、PDF、Markdown 导出与模板预览。
- 数据安全、提示词注入防护、AI 使用声明和可追溯记录。

暂不纳入当前版本的范围：

- 多端云同步与账号体系。
- 学校专属模板市场。
- 付费数据库全文获取。
- 自动完成整篇论文。

## 2. 安全与 AI 测试修复计划

| 类型 | 已完成处理 | 后续计划 |
| --- | --- | --- |
| 提示词注入 | 已对系统提示和不可信输入做隔离，新增安全冒烟测试 | 增加更多恶意样本文本，覆盖文献摘要、网页结果和用户粘贴内容 |
| API Key 安全 | API Key 仅本地保存，备份默认不包含 Key | 增加首次配置时的隐私说明弹窗 |
| XSS 风险 | 页面输出统一使用 `escapeHtml`，AI 结果写入前清洗 | 增加自动化 DOM 注入测试 |
| AI 超时 | 真实调用配置超时和错误提示，生成初稿支持流式输出 | 增加全局请求队列和取消按钮的一致样式 |
| AI 伦理 | 导出物加入 AI 辅助使用声明，项目设置页展示使用记录 | 增加按章节导出的 AI 使用明细 |

## 3. 同行评审回应计划

| 反馈类型 | 处理策略 |
| --- | --- |
| 流程不清晰 | 继续减少一次性展示的模块，优先采用问卷式、分页式交互 |
| 写作台拥挤 | 保留核心工具在顶部，低频工具进入菜单或弹窗 |
| 导出格式差异 | 保留通用模板，同时开放字体、字号、页边距、行距等设置 |
| 文献来源不足 | 扩展开放数据库来源，并强化手动补全文献入口 |
| AI 输出质量波动 | 提供重新生成、用户反馈再生成和人工编辑入口 |

正式外部评审完成后，将逐条标记“采纳 / 部分采纳 / 暂不采纳”，并形成对应 commit。

## 4. 后续版本规划

| 优先级 | 方向 | 说明 |
| --- | --- | --- |
| P0 | 稳定性 | 增加端到端自动化测试，覆盖研究设计、写作台、文献同步和导出 |
| P1 | 模板能力 | 支持更多学校模板参数、封面字段和目录更新说明 |
| P1 | 文献能力 | 增加 DOI 补全、BibTeX/RIS 导入和引用一致性整理 |
| P2 | 协作与备份 | 支持导出项目包、跨设备恢复和可选云同步 |
| P2 | 评审助手 | 形成导师意见、答辩意见、修改说明的跟踪闭环 |

## 5. 上线维护方案

- 每次上线前执行 `npm run build` 和 `npm run test:security`。
- 重要功能修改必须独立分支、独立 commit、通过 PR 合并。
- 发布后检查 GitHub Pages 线上页面，重点验证静态资源路径和交付文档入口。
- 保留 `report/dev-log.md` 和 `report/conversation-log.md` 作为过程追溯材料。
