# PaperPilot 项目交接包

## 1. 访问方式

- 在线系统：https://kevinnzou.github.io/paper-pilot/
- 交付文档页：https://kevinnzou.github.io/paper-pilot/delivery.html
- 代码仓库：https://github.com/KevinnZou/paper-pilot

系统为浏览器本地应用，不要求登录即可使用。项目数据默认保存在当前浏览器 IndexedDB 中，API Key 仅在用户本机浏览器保存和调用，不经过项目自有服务器。

## 2. 核心功能清单与 DoD

| 模块 | Must have | DoD 标准 | 状态 |
| --- | --- | --- | --- |
| 项目创建与管理 | 支持创建、切换、删除论文项目 | 能创建带题目/学位类型/基础信息的项目，并在浏览器本地持久化 | 已完成 |
| 研究设计 | 低输入问卷式生成题目、研究方案和大纲 | 用户选择题目、研究问题、方法、数据来源和范围后，可生成并采用大纲 | 已完成 |
| 写作台 | 按章节写作、目录跳转、富文本编辑、AI 辅助 | 支持章节定位、引用/图片/表格/公式/注释、AI 初稿、润色、论证、续写和逻辑检查 | 已完成 |
| 文献与证据 | 文献检索、入库、证据卡管理 | AI 初稿检索到的文献可同步到文献库，证据可新增和关联章节 | 已完成 |
| 排版与导出 | 模板预览、Word/PDF/Markdown 导出 | 预览支持分页，导出带题名页、目录、章节、参考文献和 AI 辅助声明 | 已完成 |
| 数据安全 | 本地存储、备份恢复、提示词注入防护 | API Key 不上传自有服务器；AI 调用前隔离不可信输入；可导出和恢复备份 | 已完成 |
| 测试与上线 | 构建、功能、安全、上线验证 | `npm run build`、安全冒烟测试、GitHub Pages 部署流程可通过 | 已完成 |

## 3. 已知问题

| 问题 | 影响 | 当前处理 |
| --- | --- | --- |
| 不同学校论文模板存在差异 | 导出格式需要按院校细则微调 | 提供通用学位论文模板和项目设置中的格式参数 |
| 浏览器本地存储与设备绑定 | 换电脑后默认看不到原项目 | 提供导出备份和导入恢复 |
| 学术数据库开放 API 覆盖有限 | 中文数据库和付费论文无法完全自动获取 | 使用 CrossRef/OpenAlex 等开放来源，并支持手动补充文献 |
| AI 输出存在不稳定性 | 可能返回格式异常或质量不足 | 已加入模拟模式、错误提示、重新生成、人工编辑与最终审核流程 |

## 4. 验收建议

1. 新建项目，完成研究设计问卷并采用大纲。
2. 进入写作台，生成一个章节初稿并检查文献库是否同步新增文献。
3. 插入图片、表格、注释和引用，执行导出前检查。
4. 分别导出 Word、PDF 和 Markdown，确认分页、目录、参考文献和 AI 辅助声明存在。
5. 在设置页导出备份，再导入恢复，确认项目数据可回溯。
