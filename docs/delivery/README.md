# PaperPilot 交付文档目录

本目录用于集中放置最终交付和答辩可用的项目文档。

- [开发报告](./development-report.md)：偏最终总结，说明项目背景、产品定位、技术实现、测试验收和上线结果。
- [标准化开发过程文档](./development-process-document.md)：偏过程追溯，覆盖产品分析、竞品调研、商业分析、PRD、视觉稿、技术方案、测试方案、上线方案等完整流程。
- [安全测试说明](./security-test-report.md)：说明数据安全、API Key 保护、提示词注入防护、XSS 防护和安全测试用例。
- [测试用例清单](./test-cases.md)：整理构建、功能、AI、文献、导出、设置、安全和上线测试用例。

配套材料位于：

- `docs/analysis/`：市场、竞品、用户分析。
- `docs/research/`：调研原始整理。
- `docs/review/`：页面截图和视觉证据。
- `report/`：开发日志、对话日志、合规审计和缺陷记录。
