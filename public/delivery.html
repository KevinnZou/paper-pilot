标准化开发流程

项目按标准产品开发链路推进，而不是直接从代码开始。

  1. 1
    产品分析

    明确论文写作痛点、产品定位、使用边界和学术诚信原则。

  2. 2
    竞品调研

    分析通用 AI、论文写作工具和文献管理工具，识别差异化机会。

  3. 3
    商业分析

    判断 BYOK 免费内测、托管额度、云同步和学校采购等后续路径。

  4. 4
    PRD

    用 MoSCoW 划分需求优先级，并形成论文项目主线。

  5. 5
    视觉稿

    形成纸墨朱砂视觉系统，沉淀主要页面截图和 UI/UX 审计记录。

  6. 6
    技术方案

    确定 Vite、ProseMirror、本地存储、OpenAI 兼容 API 和 Pages 架构。

  7. 7
    测试方案

    覆盖构建、主流程、真实 API、导出、视觉和上线验证。

  8. 8
    上线方案

    通过 GitHub Actions 构建 dist 并发布到 GitHub Pages。
