# PaperPilot · 论文写作助手

面向在校学生的轻量级论文写作辅助系统——覆盖「选题 → 写作 → 文献 → 进度」全流程，内置写作计划管理与 GB/T 7714 国标引用，坚持学术诚信合规导向。

清华大学MEM《项目管理》课程作业 · AI 辅助开发项目。

当前版本：`4.0.0-beta.1`。

## 功能

- **论文主页**：五步写作之旅引导、关键数字（截止天数/进度/字数/连续打卡）、章节进度直达写作
- **选题与大纲**：选题建议生成（可一键设为题目）、研究框架与章节大纲生成、选题后批量文献推荐
- **写作工作台**：稿纸式编辑器承载一份完整论文文档（题目/摘要/关键词/各章/参考文献/致谢），目录点击定位，润色/扩写/降重/续写/初稿生成作用于当前内容，正文只插 [n] 序号，文末参考文献自动生成；支持模板预览、Word/PDF/Markdown 导出、格式整理、引用整理、图片/表格/公式/注释插入、版本保存与撤销/重做
- **文献中心**：CrossRef/OpenAlex 真实数据库检索（中英双语通道、AI 检索策略+推荐理由、分页「加载更多」）、GB/T 7714 规则引擎、杂乱引用 AI 解析、手动录入、文献库实时搜索（标题/作者/出处）、正文引用同步、证据卡管理
- **计划与进度**：可选截止日期倒排时间轴、今日任务、每日打卡与章节进度记录
- **设置**：BYOK 大模型 API 配置（DeepSeek 默认，兼容 OpenAI 协议）、演示数据一键载入、本地数据管理、备份导出/导入（含 API Key，文件勿外传）

## 设计语言

「纸墨朱砂」——从论文写作的器物取材：纸色底、宋体标题、等宽数字。红色是 AI 的朱批：AI 动作按钮、生成结果的批注轨、学术诚信提示均为朱砂；完成态统一松烟绿印章标记（已入库 / 已采用 / 已打卡）。颜色承载语义，不做装饰。

## 使用方法

1. **本地测试**：项目根目录运行 `npm run dev`，浏览器访问 http://localhost:8001/；**线上使用**：先运行 `npm run build`，再部署 `dist/`
2. 进入「设置」，填入你的大模型 API Key（默认 DeepSeek，兼容任何 OpenAI 协议服务商）
3. 如暂不想消耗真实 API，可在设置中关闭真实调用，使用演示结果走完整流程
4. 从「研究设计」定题并生成大纲，随后进入「论文写作」开始写作

## 本地预览

本项目为前端单页应用，使用 Vite 进行本地开发和生产构建：

```sh
npm install
npm run dev                    # http://localhost:8001/
npm run build                  # 输出 dist/
npm run preview                # http://localhost:4173/
```

若只想用静态服务器预览源码，也可以运行 `sh tools/serve.sh [端口]`，但发布版本建议使用 `npm run build` 生成的 `dist/`。

## 隐私说明

- 本应用**无后端**：请求从你的浏览器直接发送到模型服务商
- API Key 仅保存在本机浏览器的 localStorage 中，不会上传到任何服务器
- 文献库、写作计划、打卡记录等所有数据均保存在本地
