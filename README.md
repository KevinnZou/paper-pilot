# PaperPilot · 论文写作助手

面向在校学生的轻量级论文写作辅助系统——覆盖「选题 → 写作 → 文献 → 进度」全流程，内置写作计划管理与 GB/T 7714 国标引用，坚持学术诚信合规导向。

清华大学MEM《项目管理》课程作业 · AI 辅助开发项目。

## 功能

- **论文主页**：五步写作之旅引导、关键数字（截止天数/进度/字数/连续打卡）、章节进度直达写作
- **选题与大纲**：选题建议生成（可一键设为题目）、研究框架与章节大纲生成、选题后批量文献推荐
- **写作工作台**：稿纸式编辑器承载一份完整论文文档（题目/摘要/关键词/各章/参考文献/致谢），目录点击定位，润色/扩写/降重/续写/初稿生成作用于选中文字，正文只插 [n] 序号、文末参考文献自动生成，「排版预览」可打印/另存 PDF，「下载全文」一键导出 Markdown；学位目标字数实时提示（未达下限朱砂 / 已达下限松烟绿 ✓）；触屏撤销/重做按钮（键盘 Ctrl+Z/Y 等效）；插入引用支持未引用文献排序优先 + 编号直达
- **文献中心**：CrossRef/OpenAlex 真实数据库检索（中英双语通道、AI 检索策略+推荐理由、分页「加载更多」）、GB/T 7714 规则引擎、杂乱引用 AI 解析、手动录入、文献库实时搜索（标题/作者/出处）、引用状态自查（已引用/未引用 + GB/T 7714 统计行）
- **计划与进度**：截止日期倒排甘特图（当前阶段朱砂描边）、每日打卡关联章节进度
- **设置**：BYOK 大模型 API 配置（DeepSeek 默认，兼容 OpenAI 协议）、演示数据一键载入、本地数据管理、备份导出/导入（含 API Key，文件勿外传）

## 设计语言

「纸墨朱砂」——从论文写作的器物取材：纸色底、宋体标题、等宽数字。红色是 AI 的朱批：AI 动作按钮、生成结果的批注轨、学术诚信提示均为朱砂；完成态统一松烟绿印章标记（已入库 / 已采用 / 已打卡）。颜色承载语义，不做装饰。

## 使用方法

1. **本地测试**：项目根目录运行 `sh tools/serve.sh`，浏览器访问 http://localhost:8000/index.html（见下文「本地预览」）；**线上使用**：部署到 GitHub Pages / Netlify 后直接访问
2. 进入「设置」，填入你的大模型 API Key（默认 DeepSeek，兼容任何 OpenAI 协议服务商）
3. 在「计划与进度」设定论文截止日期，生成写作计划
4. 开始使用各模块的 AI 功能

## 本地预览

本项目为纯静态前端（无后端、无构建步骤），但现代浏览器**禁止通过 `file://` 协议加载 ES 模块**，因此本地测试需起一个静态文件服务器（零依赖）：

```sh
sh tools/serve.sh              # 默认端口 8000
# 或手动：python3 -m http.server 8000
```

浏览器访问 http://localhost:8000/index.html（部署到 https 环境后无此限制）。

## 隐私说明

- 本应用**无后端**：请求从你的浏览器直接发送到模型服务商
- API Key 仅保存在本机浏览器的 localStorage 中，不会上传到任何服务器
- 文献库、写作计划、打卡记录等所有数据均保存在本地
